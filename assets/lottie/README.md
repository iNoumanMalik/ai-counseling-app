# Lottie Animations Directory

Place your Lottie animation JSON files here.

## Recommended Animations

- Mood animations (happy, sad, anxious, calm, etc.)
- Breathing animations
- Loading animations
- Success checkmarks
- Celebration animations

## Download Lottie Files

You can find free Lottie animations at:
- LottieFiles: https://lottiefiles.com
- Use the `lottie` package to load: `Lottie.asset('assets/lottie/animation.json')`
